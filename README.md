# sandi-app

Rojstnodnevna šala: lažen oglas za nepremičnino (prvo nadstropje doma) v stilu portalov za nepremičnine. Statična stran (HTML/CSS/JS), primerna za GitHub Pages.

## Zagon lokalno

```sh
python3 -m http.server 8000
# odpri http://localhost:8000
```

## Objava na GitHub Pages

Settings → Pages → Source: `main` / `(root)`.

## Zamenjava slik (npr. AI vizualizacije po obnovi)

Slike so v `img/`. Zamenjaj datoteko z istim imenom, ali uredi seznam `PHOTOS` na vrhu [script.js](script.js) (pot + podnapis).
